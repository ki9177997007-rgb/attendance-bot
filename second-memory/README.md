# Вторая память 0.4

Одна кнопка ВКЛ/ВЫКЛ. Один поток AudioRecord одновременно сохраняет WAV и передаёт звук в Vosk. Запись работает в foreground service с уведомлением, не привязана к экрану Activity. После принудительной остановки или перезагрузки включается только пользователем.

При первом включении говорите в одиночестве: три фразы по 5–10 секунд с паузами. Для каждой нужны минимум 400 речевых кадров; слишком короткие или непохожие фразы не входят в образец. Профиль сохраняется локально. Долгое нажатие единственной кнопки открывает меню: подключение YouGile, доступ к записям, синхронизация, сброс голосового образца с подтверждением.

Модель Vosk speaker 0.4 сравнивает векторы по косинусному сходству. Порог 0.65 — предварительная настройка, не измеренная точность. Пометка «похож на твой голос» не является удостоверением личности. Короткие фразы и сомнительные совпадения сохраняются без приоритета. Перекрывающиеся голоса не разделяются. Качество русского текста ограничено небольшой офлайн-моделью ru 0.22, улучшение относительно системного движка не гарантировано.

Данные: files/sessions/<дата>/audio_*.wav (по пять минут), transcript.txt, transcript.jsonl, priority.txt. Все реплики сохраняются; приоритетные дополнительно выделяются. Резервное копирование отключено. Удаление приложения удаляет внутренние записи. После выключения копии TXT сохраняются в Downloads/VtorayaPamyat (Android 10+). Аудио и TXT доступны через системный файловый выбор в разделе «Вторая память». JSON с голосовыми векторами не публикуется файловым провайдером.

## YouGile напрямую

При первом запуске откроется однократный вход YouGile; можно отложить и работать офлайн. Пароль отправляется только на https://yougile.com/api-v2 и не сохраняется. При нескольких компаниях пользователь выбирает компанию. Создаётся отдельный проект «Вторая память», доска «Поручения из разговоров» и две колонки для проверки: приоритетные и с неподтверждённым говорящим. Существующие проекты не изменяются. API-ключ хранится зашифрованным AES-GCM, ключ шифрования — Android Keystore. Supabase и промежуточные серверы не используются.

На телефоне выделяются ЧЕРНОВИКИ по правилам явных команд («задача», «нужно», «Олег, подготовь» и др.). Это не LLM и не полный смысловой разбор разговора. Отрицания и условные формулировки по поддержанным правилам пропускаются. Автоматические назначения исполнителей и расчёт сроков не выполняются, исходная фраза остаётся в черновике. Обучающие реплики в задачи не попадают. В YouGile уходят только фразы-поручения и локальный идентификатор записи, не весь разговор и не аудио.

SQLite-очередь сохраняется при перезапуске. Стабильные idempotencyKey предотвращают повторное создание после потери ответа сервера. Отправка/чтение статусов — примерно раз в минуту во время записи и при открытии/остановке, в фоне через JobScheduler не чаще системного интервала 15 минут, без гарантии точного времени. Отметка completed в YouGile обновляет локальный tasks.txt. Программа не закрывает задачи по неоднозначным словам в разговоре. При ошибке сети очередь остаётся на устройстве. Реальная авторизация и обмен должны быть проверены после входа пользователя.

## Проверка

JUnit: сравнение голосов, WAV, отбор команд/отрицаний, повторная настройка проекта с теми же idempotencyKey, повтор отправки после потери ответа. YouGile тестируется подставным транспортом; это не подтверждение живого подключения. Android lint и assembleDebug выполняются в CI.

Сборка: Python 3, JDK 17, Android SDK 35, Gradle 8.9. Выполнить `python3 scripts/prepare_models.py`, затем `gradle testDebugUnitTest lintDebug assembleDebug`. Модели скачиваются с официального сервера при сборке и включаются в APK. Vosk: https://github.com/alphacep/vosk-api, модели: https://alphacephei.com/vosk/models. Модели распространяются с файлами лицензий upstream в архивах.

На реальном устройстве проверить: разрешение/отказ, первый запуск, обучение в тишине, другой говорящий, короткие фразы, блокировка экрана, поворот экрана, остановка через уведомление, быстрые повторные нажатия, конфликт с звонком, недостаток места. Автотесты проверяют сравнение голосов и целостность WAV, но не измеряют качество распознавания.

Версия 0.4 устанавливается рядом с прежним прототипом (applicationId ru.secondmemory.mobile), чтобы не требовать удаления его записей при несовпадении отладочных подписей. Старые записи автоматически не импортируются.
