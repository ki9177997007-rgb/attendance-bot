# Вторая память 0.5

Главный экран — ВКЛ/ВЫКЛ. Удержание кнопки: поручения, сотрудники, нейросеть, точные напоминания, YouGile и записи. Однократная загрузка Qwen2.5-1.5B-Instruct Q4_K_M (1 117 320 736 байт) из официального репозитория Qwen, с проверкой SHA-256. Выбор Wi-Fi или любой сети. После загрузки смысловой разбор работает локально, без платного API. Модель не включена в APK; Android DownloadManager продолжает загрузку в фоне.

Vosk сохраняет русскую речь и WAV офлайн. Голосовой образец — три фразы по 5–10 секунд в одиночестве. Похожий голос получает приоритет; это вероятностная оценка, не надёжная идентификация. Перекрывающиеся голоса не разделяются. Качество распознавания требует проверки на устройстве.

После выключения записи JobScheduler запускает Qwen через llama.cpp на CPU. Разбор по репликам с ограниченным предыдущим контекстом; прогресс сохраняется. При включении микрофона обработка откладывается. Android может откладывать фоновое задание. Модель выдаёт один черновик на реплику: действие, исполнитель, срок. Объединённые поручения в одной реплике могут требовать ручного разделения. Ответ ограничен JSON-грамматикой. Неудачные ответы отмечаются в ai-review.txt; оригиналы не удаляются. Очень длинные реплики остаются для ручной проверки. До загрузки модели используются консервативные правила команд без фиксированных имён.

Сотрудники задаются через меню, по одному на строку. Ранее записанные поручения не переименовываются автоматически при изменении состава. Результаты модели — черновики, их можно изменить в списке поручений. Исполнитель хранится как текст; автоматического сопоставления с пользователем YouGile нет.

Напоминания: явные числовые интервалы и время распознаются правилами сразу; поддерживаются числительные словами, завтра/послезавтра, дни недели и даты с названием месяца. Дата будильника рассчитывается проверяемым парсером исходной реплики: выдуманный моделью срок игнорируется. Неоднозначные сроки нужно назначить вручную. Ручной выбор даты и времени доступен в поручении. Разрешите уведомления и точные будильники в меню. Без точного разрешения применяется неточный AlarmManager, возможна задержка. Сохранённые напоминания восстанавливаются после перезагрузки/обновления; выполнение выключает дальнейшее напоминание. Насильственная остановка Android блокирует фон до следующего открытия приложения.

SQLite мигрирует с версии 1 на 2, сохраняя прежние задачи. v0.5 использует тот же applicationId ru.secondmemory.mobile; APK для пользователя подписывается тем же сохранённым ключом, что и v0.4. Устанавливать поверх v0.4, не удаляя приложение. После старого прототипа с другим applicationId записи автоматически не импортируются.

YouGile подключается через отдельное меню. Ключ защищён Android Keystore; речь и аудио не отправляются. Передаются черновики поручений, исполнитель и срок в описании, статусы выполнения. Изменения локальных задач отправляются при синхронизации. Удалённое выполнение читается обратно. Обмен примерно раз в минуту при записи и периодически в фоне; реальный вход требует проверки с аккаунтом пользователя. Без YouGile задачи и напоминания работают локально.

Сборка: JDK 17, Gradle 8.9, SDK 35, NDK 27.2.12479018, CMake 3.22.1; ARM64 (включая Samsung SM-S931B). В vendor/llama.cpp нужен commit 74d4f5b041ad837153b0e90fc864b8290e01d8d5. Затем python3 scripts/prepare_models.py и gradle testDebugUnitTest lintDebug assembleDebug. CI дополнительно собирает тот же C++ движок для Linux и проверяет настоящий запуск Qwen на русских фразах.

Ручная приёмка на телефоне: обновление с сохранением записей; загрузка модели; профиль голоса; запись при блокировке; поручение новому сотруднику; срок через пять минут; уведомление при закрытом экране; перезагрузка; выполнение и редактирование; подключение YouGile. Проверки CI не подтверждают скорость, качество микрофона или надёжность фоновой работы на конкретном телефоне.
