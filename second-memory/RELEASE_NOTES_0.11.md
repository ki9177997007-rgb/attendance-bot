# Вторая память 0.11 — тестовое обновление доставки расшифровок

Добавлена локальная очередь исходящих расшифровок, восстановление из исходных журналов, отдельные подтверждения для каждого получателя, проверка идентификатора и SHA-256 ответа. Настройка архива хранится через Android Keystore; передача отключена до её настройки. Перенаправления HTTP запрещены. Исходные аудио и текст при передаче не удаляются.

В настройках добавлен экран «Архив для ChatGPT»: импорт файла подключения, сохранение, повтор передачи и отключение. До загрузки конфигурации данные на сервер не отправляются. YouGile использует прежний отдельный экран подключения.

Проверки кода приложения: unit-тесты, lintDebug, assembleDebug и smoke локальной модели прошли. На Android 35 emulator прошли 11 инструментальных тестов, включая 2 новых теста сохранности очереди и отказа при конфликтующем повторе. Четыре теста серверного валидатора прошли отдельно. Проверка эмулятора не подтверждает качество живого микрофона или фоновую устойчивость Samsung пользователя.

У пользовательского APK проверены подпись и идентичность сертификата v10, applicationId ru.secondmemory.assistant, versionCode 11. Перед удалением старого приложения следует сохранить данные: обновление предназначено для установки поверх v10. Эмулятором не проверялось обновление именно с пользовательской подписанной v10.

## Не завершено

- Доставка реального фрагмента с телефона и сетевой отказ при неверном ключе.
- Дедупликация строк облачного приёмника при параллельных повторах. Клиент сохраняет стабильные идентификаторы и контрольные суммы, но это не равно exactly-once.
- Подключение конкретного аккаунта YouGile и реальный обмен задачами.
- Автоматический запуск анализа именно в ChatGPT после поступления файла.
- Фоновый голосовой диалог, слово обращения и проверка голоса владельца.

Облачный приёмник остаётся черновиком. Публичный тариф сервиса автоматизации имеет квоты; непрерывную отправку каждой реплики нельзя считать бесплатной без проверки плана и перехода к пакетной отправке. Платные модели и автоматический анализ не включены.

Это промежуточная техническая сборка, а не законченный помощник памяти.
