# Подключение VK: Подарочный переполох

Сообщество: https://vk.com/club242557906 (ID 242557906).

## Проверенный технический маршрут

1. Использовать официальный пользовательский OAuth VK с разрешением `video`. Для авторизации может понадобиться зарегистрированное приложение VK ID. Не путать с ключом сообщества: метод `video.save` требует пользовательский токен.
2. Токен не отправлять в чат, не помещать в исходники и URL GitHub. Сохранить в **Settings → Secrets and variables → Actions → New repository secret**, имя `VK_ACCESS_TOKEN`.
3. Запускать workflow **Free Video Factory** из ветки `video-factory-free`, указав `publish_vk=true`. При этом он вызовет `video_factory/vk_upload.py` с `VK_GROUP_ID=242557906`.
4. Проверить ссылку на опубликованное видео и наличие записи на стене. Раздел VK Клипы не гарантируется: `video.save` загружает обычное видео.

## Важно

На момент создания инструкции OAuth-токен не получен и тестовый запуск не проводился. Нельзя считать автопубликацию подключённой. Для работы без участия пользователя потребуется поддерживаемый VK срок действия и обновление токена. Не запускать расписание до проверки авторизации и формата публикации.

Официальная схема: https://github.com/VKCOM/vk-api-schema/blob/master/video/methods.json и https://github.com/VKCOM/vk-php-sdk/blob/master/README.md
